## Overview

BaseStaking is a non-custodial ETH staking protocol on Base mainnet with multiple lock periods and reward tiers.

## Lock Periods & APY

| Period | APY |
|--------|-----|
| 30 Days | 5% |
| 90 Days | 10% |
| 180 Days | 15% |

## Features

- Multiple lock period options
- Early unstake with 10% penalty
- Top 1000 stakers leaderboard
- Pending rewards tracking
- Emergency pause by owner
- Non-custodial — your ETH, your control
